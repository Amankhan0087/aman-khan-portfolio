## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/Amankhan0087/aman-khan-portfolio.git
```

Go to the project folder:

```bash
cd aman-khan-portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
